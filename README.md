## 🚀 Εγκατάσταση & Εκτέλεση

### Τοπικά

```bash
# 1. Κλωνοποίηση
git clone https://github.com/chiinsurancebrokers/grammateas.git
cd grammateas

# 2. Εικονικό περιβάλλον
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

# 3. Εξαρτήσεις
pip install -r requirements.txt

# 4. Μεταφορά δεδομένων (ΜΟΝΟ αν έχετε παλιά βάση lodge_members.db)
python migrate.py --old lodge_members.db --new grammateas.db

# 5. Εκτέλεση
streamlit run app.py
```

### Streamlit Cloud (https://share.streamlit.io)

1. Push το repository στο GitHub
2. Streamlit Cloud → "New app" → επιλέξτε το repo
3. Main file: `app.py`
4. Deploy!

> **Σημείωση:** Η βάση `grammateas.db` δημιουργείται αυτόματα κατά την πρώτη εκκίνηση.  
> Στο Streamlit Cloud τα δεδομένα **δεν αποθηκεύονται μόνιμα** — χρησιμοποιήστε  
> [Streamlit Community Cloud + GitHub Codespaces] ή τοπική εγκατάσταση για παραγωγή.

## 🔄 Μεταφορά Δεδομένων

Αν έχετε ήδη δεδομένα στην παλιά βάση `lodge_members.db`:

```bash
python migrate.py
# ή
python migrate.py --old /path/to/lodge_members.db --new grammateas.db
```

Το script μεταφέρει αυτόματα τα 40 μέλη με αντιστοίχιση πεδίων.
